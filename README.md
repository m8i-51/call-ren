# コール練

スタンドをかけたまま、バイクの「コール」（スロットルで刻む排気のリズム）を練習するウェブアプリです。音は録音ではなく、ブラウザの Web Audio でその場で合成します。

公道での空吹かしや暴走を促すものではありません。音とリズムの玩具です。

## 起動

```bash
npm i
npm run dev
```

開発サーバーは <http://localhost:4317> で開きます。

本番用の静的ファイルは次で出力します。

```bash
npm run build
npm run preview
```

## 遊び方

1. 「タップしてエンジンをかける」で音を有効にします。
2. **フリー**: 下（広い画面では右）のグリップを押し込んで回転を上げ、離すと戻ります。気筒・直管／マフラー・荒さで排気の性格が変わります。
3. **練習**: 型を選んでスタート。カウントの「ハイ」のあと、レーンの山に合わせて開けます。判定はジャスト / 早い / 遅い / 浅い / ミス。70点以上で合格です。
4. 「お手本」で、その型をエンジンが一度吹きます。
5. デスクトップではスペースキー / W / ↑ の長押しで全開になります。
